預算線、無異曲線與最適選擇

這一頁不在作業範圍裡，但 HW6 到 HW9 每一題都會用到。只要記住一件事：消費者在預算線上，挑一個落在最高那條無異曲線上的點。後面四章都是這句話的變形。

預算線：買得起的邊界

手上有 $m$ 元，兩種商品的價格是 $p_1$、$p_2$。剛好把錢花光的所有組合連起來，就是預算線（budget line）。線上和線下的組合都買得起，合起來叫預算集合（budget set）。

$$p_1x_1 + p_2x_2 = m$$

橫軸截距 $\dfrac{m}{p_1}$（錢全部買商品 1）　縱軸截距 $\dfrac{m}{p_2}$（錢全部買商品 2）　斜率 $-\dfrac{p_1}{p_2}$

斜率 $-p_1/p_2$ 的意思是：多買 1 單位 $x_1$，就得少買 $p_1/p_2$ 單位 $x_2$。這是市場上兩種商品的交換比例，也叫相對價格（relative price）。

  1. 所得 $m$ 變動：兩個截距一起變，斜率不變 → 平行移動。
  2. 一個價格變動：只有那個商品的截距在變，另一軸的截距不動 → 繞著另一軸的截距旋轉。$p_1$ 上漲，線變陡；$p_1$ 下跌，線變平。

後面會一直回來用這兩條規則：Ch8 把「旋轉」拆成兩步，Ch9 的預算線改成繞著稟賦點轉，Ch10 把兩個軸換成今天和明天的消費。

$p_1 = 2$、$p_2 = 1$、$m = 40$。如果 $p_1$ 漲到 4，其他不變，預算線會怎麼動？

$p_2$ 和 $m$ 沒變，所以縱軸截距 $m/p_2 = 40$ 不動。橫軸截距從 $40/2 = 20$ 縮到 $40/4 = 10$，斜率從 $-2$ 變成 $-4$，更陡。

偏好與無異曲線

預算線說的是「買得起什麼」，偏好（preference）說的是「喜歡什麼」。比較兩個組合 $x$ 和 $y$ 只有三種結果：

記號念法意思
$x \succ y$嚴格偏好（strictly preferred）$x$ 比 $y$ 好
$x \sim y$無異（indifferent）一樣好
$x \succsim y$弱偏好（weakly preferred）$x$ 至少跟 $y$ 一樣好

經濟學假設偏好滿足三件事，這樣才能排出順序：

  • 完整性（completeness）：任兩個組合都比得出來。
  • 反身性（reflexivity）：任何組合至少跟自己一樣好。
  • 遞移性（transitivity）：$x \succsim y$ 且 $y \succsim z$，就有 $x \succsim z$。Ch7 的「間接顯示性偏好」用的就是這一條。

單調（monotonic）：東西越多越好，所以無異曲線斜率是負的。
凸（convex）：喜歡平均勝過極端，所以無異曲線凸向原點。

兩個加起來，預算線上最喜歡的組合就只有一個。Ch7 整章都靠這個假設。

把一樣好的組合連起來就是無異曲線（indifference curve）。越往右上的無異曲線效用越高，而且兩條無異曲線不能相交（相交會違反遞移性）。

MRS 就是無異曲線在那一點的斜率：多拿 1 單位 $x_1$，願意放棄多少 $x_2$，還覺得一樣好。

$$\text{MRS} = \frac{dx_2}{dx_1} = -\frac{MU_1}{MU_2} \qquad MU_1 = \frac{\partial U}{\partial x_1},\quad MU_2 = \frac{\partial U}{\partial x_2}$$

老師的簡報把 MRS 定義成帶負號的斜率，所以最適條件寫成 $\text{MRS} = -p_1/p_2$。題目要你「比較 MRS 和相對價格」時，比的是大小，請用絕對值 $|\text{MRS}|$ 去和 $p_1/p_2$ 比，不要被負號搞混。

四種常見的效用函數

效用函數（utility function）只是幫每個組合打一個分數，分數高的比較好。考試會出現的就是下面四種，看到式子要馬上知道無異曲線長什麼樣子、最適解要用哪一招。

效用是序數（ordinal）的：分數只用來排順序，數字本身大小沒意義。所以把效用函數做單調轉換（monotonic transformation），例如平方、乘以 2、取 $\ln$，偏好完全不變，MRS 也不變。$U = x_1^2x_2$ 和 $U = 2\ln x_1 + \ln x_2$ 是同一種偏好。

$U = \min\{x_1,\, 2x_2\}$。下面哪一個組合跟 $(4, 2)$ 一樣好？

$U(4,2) = \min\{4, 4\} = 4$。$U(8,2) = \min\{8, 4\} = 4$，一樣好：多出來的 $x_1$ 沒有 $x_2$ 搭配，完全沒用。$U(2,4) = \min\{2, 8\} = 2$ 比較差；$U(6,3) = \min\{6, 6\} = 6$ 比較好。

最適選擇：三種解法

消費者要在預算集合裡找最喜歡的組合，叫最適選擇（optimal choice），也就是一般需求（ordinary demand）$x_1^*(p_1, p_2, m)$、$x_2^*(p_1, p_2, m)$。依無異曲線的形狀，有三種找法。

解法一：相切解（Cobb-Douglas）

(a) 花光預算：$p_1x_1^* + p_2x_2^* = m$
(b) 相切：無異曲線的斜率 = 預算線的斜率，也就是 $\text{MRS} = -\dfrac{p_1}{p_2}$

以 $U = x_1^a x_2^b$ 來說，$\text{MRS} = -\dfrac{a\,x_2}{b\,x_1}$。把兩個條件聯立解出來，會得到一個值得背起來的結果：

$$x_1^* = \frac{a}{a+b}\cdot\frac{m}{p_1} \qquad\qquad x_2^* = \frac{b}{a+b}\cdot\frac{m}{p_2}$$

花在商品 1 的錢永遠是所得的 $\dfrac{a}{a+b}$，花在商品 2 的是 $\dfrac{b}{a+b}$，跟價格無關。

看推導：以 U = x₁²x₂ 為例（作業 HW7 第 1 題）

$MU_1 = 2x_1x_2$、$MU_2 = x_1^2$，所以 $\text{MRS} = -\dfrac{2x_1x_2}{x_1^2} = -\dfrac{2x_2}{x_1}$。

相切：$-\dfrac{2x_2}{x_1} = -\dfrac{p_1}{p_2}$，整理成 $p_2x_2 = \dfrac{p_1x_1}{2}$。

代入預算式：$p_1x_1 + \dfrac{p_1x_1}{2} = m$，所以 $x_1^* = \dfrac{2m}{3p_1}$，再代回去得 $x_2^* = \dfrac{m}{3p_2}$。

跟公式一樣：$a = 2$、$b = 1$，商品 1 拿走所得的 $\tfrac23$，商品 2 拿走 $\tfrac13$。

$U = x_1x_2^3$、$m = 80$、$p_1 = 2$、$p_2 = 5$。最適的 $x_1^*$ 是多少？

$a = 1$、$b = 3$，商品 1 拿走所得的 $\tfrac{1}{4}$，也就是 20 元，所以 $x_1^* = 20/2 = 10$。順便算 $x_2^* = \tfrac34\cdot\tfrac{80}{5} = 12$。檢查：$2\times10 + 5\times12 = 80$ ✓。

解法二：角解（完全替代）

無異曲線是直線時，斜率固定，通常沒辦法跟預算線「相切」。這時候最適解會跑到預算線的端點，叫角解（corner solution）：錢全部買比較划算的那一個。

$|\text{MRS}| = 2$：1 單位 $x_1$ 在他心裡值 2 單位 $x_2$。拿它跟市場的交換比例 $p_1/p_2$ 比：

$\dfrac{p_1}{p_2} \lt 2$：$x_1$ 比較划算，全買 $x_1$ → $\left(\dfrac{m}{p_1},\ 0\right)$
$\dfrac{p_1}{p_2} \gt 2$：$x_1$ 太貴，全買 $x_2$ → $\left(0,\ \dfrac{m}{p_2}\right)$
$\dfrac{p_1}{p_2} = 2$：一樣划算，預算線上每一點都是最適解

另一個好記的看法：比「每花 1 元買到多少效用」。$x_1$ 是 $MU_1/p_1 = 2/p_1$，$x_2$ 是 $MU_2/p_2 = 1/p_2$，哪個大就全買哪個。

$U = x_1 + 3x_2$、$p_1 = 1$、$p_2 = 2$、$m = 12$。最適組合是？

每 1 元買到的效用：$x_1$ 是 $1/1 = 1$，$x_2$ 是 $3/2 = 1.5$，$x_2$ 比較划算，所以全買 $x_2$：$12/2 = 6$。用 MRS 看也一樣：$|\text{MRS}| = \tfrac13 \lt \tfrac{p_1}{p_2} = \tfrac12$，$x_1$ 在市場上比在他心裡貴。

解法三：折點解（完全互補）

L 型無異曲線的折點沒有斜率，不能用相切。但最適解一定在折點：離開折點多買的那一樣東西沒有搭配，白花錢。所以把「折點的條件」和「花光預算」聯立就好。

折點：讓括號裡兩個東西相等，$x_1 = 2x_2$。代入 $p_1x_1 + p_2x_2 = m$：

$$p_1(2x_2) + p_2x_2 = m \quad\Rightarrow\quad x_2^* = \frac{m}{2p_1 + p_2} \qquad x_1^* = \frac{2m}{2p_1 + p_2}$$

可以想成他買的是「套餐」：一套 = 2 單位 $x_1$ 加 1 單位 $x_2$，一套要 $2p_1 + p_2$ 元，買得起 $\dfrac{m}{2p_1+p_2}$ 套。

$\min\{x_1,\, 2x_2\}$ 的折點是 $x_1 = 2x_2$（讓括號裡的兩個東西相等），不是 $x_2 = 2x_1$。係數 2 掛在 $x_2$ 前面，代表 $x_2$ 只需要 $x_1$ 的一半。寫完記得代一組數字檢查，例如 $(4, 2)$：$\min\{4, 4\}$ 兩邊相等 ✓。

$U = \min\{x_1,\, 2x_2\}$、$p_1 = 1$、$p_2 = 2$、$m = 48$。最適組合是？

折點 $x_1 = 2x_2$，代入 $x_1 + 2x_2 = 48$ 得 $4x_2 = 48$，所以 $x_2 = 12$、$x_1 = 24$。$(12, 24)$ 是把折點寫反的答案，$\min\{12, 48\} = 12$，白白多買了一堆 $x_2$。

「Derive the demand functions」這種題目有固定寫法，三步都要寫出來才有完整分數：

  1. 寫條件：相切解寫 $\text{MRS} = -p_1/p_2$；折點解寫 $x_1 = 2x_2$ 這類折點條件；角解寫 $|\text{MRS}|$ 和 $p_1/p_2$ 的三種大小關係。
  2. 跟預算式聯立：$p_1x_1 + p_2x_2 = m$，解出 $x_1^*$、$x_2^*$，答案要留著 $p_1$、$p_2$、$m$ 這些符號。
  3. 代數字：下一小題給了數字再代進去，並用「花費加起來等於 $m$」檢查一次。
