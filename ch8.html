Slutsky 方程式：替代效果與所得效果

價格一變，買的數量就跟著變。Slutsky 把這個變化拆成兩段：因為「相對價格變了」而換著買，和因為「口袋變深或變淺」而多買少買。考題永遠是同一套五個步驟，三種效用函數各練一次就會了。

降價時同時發生的兩件事

咖啡從 2 元降到 1 元。第一件事：咖啡相對茶變便宜了，你會多喝咖啡、少喝茶。第二件事：原本那一籃東西現在不用花那麼多錢，等於口袋裡多出一筆錢，你會拿去多買東西。

第一段 替代效果

英文是 substitution effect。只看「相對價格改變」造成的變化，把購買力多出來的部分先收走。

第二段 所得效果

英文是 income effect。價格不再動，只看「購買力多出來（或少掉）」造成的變化。

$$\underbrace{\Delta x_1}_{\text{需求量的總變化}} \;=\; \underbrace{\Delta x_1^{s}}_{\text{替代效果}} \;+\; \underbrace{\Delta x_1^{n}}_{\text{所得效果}}$$

任何價格變動造成的需求變化，一定可以拆成這兩段相加。

Slutsky 的做法：先把多出來的購買力收走

問題是兩件事同時發生，怎麼分開？Slutsky 的辦法是問一個假想的問題：

「價格已經變成新的了。如果我把你的所得調整到剛剛好買得起原來那一籃，你會怎麼選？」

這條假想的預算線叫補償預算線：斜率是新的價格比，而且通過原本的組合 A。在這條線上選出來的點叫 B。

  • A → B：購買力沒有變（還是剛好買得起 A），只有相對價格變了，所以是純替代效果（pure substitution effect）。
  • B → C：把收走的所得還給他，價格不動，所以是所得效果。C 就是降價後真正的選擇。
$$m' \;=\; p_1'\,x_1^{A} + p_2\,x_2^{A} \;=\; m + (p_1' - p_1)\,x_1^{A}$$

意思是「用新價格買舊組合要花多少錢」。降價時 $m' \lt m$（收走一些），漲價時 $m' \gt m$（補貼一些）。

下面是作業第 1 題的數字：$U = x_1^2x_2$、$m = 45$、$p_2 = 1$，$p_1$ 從 2 降到 1。按步驟一格一格看：

自己調價格看看

同一個人，換不同的新價格。注意橘色虛線永遠穿過 A；漲價時（$p_1' \gt 2$）兩個箭頭都往左。

五個步驟（每一題都一樣）

  1. 原本的組合 A：需求函數代入舊價格和所得 $m$。
  2. 補償所得 $m'$：用新價格買 A 要花多少錢，$m' = m + \Delta p \times (\text{A 裡那個商品的數量})$。
  3. 中間點 B：需求函數代入新價格和 $m'$。
  4. 最終的組合 C：需求函數代入新價格和原來的 $m$。
  5. 相減：替代效果 $= B - A$，所得效果 $= C - B$。檢查兩個加起來等於 $C - A$。
點用哪個價格用哪個所得代表什麼
A舊價格$m$價格變動前的選擇
B新價格$m'$（補償所得）假想的中間點，現實中不會真的發生
C新價格$m$價格變動後的選擇

$m'$ 是用新價格乘舊數量，不是用舊價格。另外替代效果是 $B - A$、所得效果是 $C - B$，順序寫反整題就錯。變的是哪個商品的價格，$\Delta p$ 就乘哪個商品在 A 裡的數量。

所得 100，$p_1$ 從 4 降到 2，原本買了 $x_1 = 10$。補償所得 $m'$ 是多少？

$m' = m + (p_1' - p_1)\,x_1 = 100 + (2 - 4)\times 10 = 80$。降價讓原來那一籃便宜了 20 元，所以要收走 20 元才是「剛好買得起」。

兩個效果的方向：正常財、劣等財、Giffen 財

替代效果：一定讓需求量增加或不變，永遠跟價格反方向。降價就多買，漲價就少買，沒有例外。

所得效果：降價等於實質所得增加。正常財（normal good）所得增加會多買；劣等財（income-inferior good）所得增加反而少買。

財貨類型替代效果所得效果總效果（降價時）需求曲線
正常財 normal＋＋（互相加強）買更多一定負斜率
劣等財 inferior＋−（比較小）還是買更多負斜率
Giffen 財＋−（比較大）買更少正斜率，違反需求法則

所以需求法則（Law of Downward-Sloping Demand）對正常財一定成立。Giffen 財是劣等財裡的極端情況：所得效果大到蓋過替代效果。

為什麼替代效果不可能反方向？

用上一章的顯示性偏好想。補償預算線通過 A，所以線上在 A 左上方的那一段，在原本的預算線底下都買得起，當初卻選了 A，表示那些點都不比 A 好。現在他不會跑去選那一段，只會留在 A 或往變便宜的商品那一側移動。

某商品降價後，替代效果讓需求量 +6，所得效果讓需求量 −2。這個商品是？

降價時所得效果是負的，表示實質所得增加反而少買，是劣等財。但總效果 $6 - 2 = +4$ 還是正的，降價後買更多，需求曲線仍是負斜率，所以不是 Giffen 財。

三個特例（簡報最後的 Examples）

簡報列了三種效用函數，各有一個很乾淨的結論。前兩個就是作業第 2、3 題。

完全互補：替代效果是 0

$U = \min\{x_1, 2x_2\}$、$p_1 = 1$、$m = 48$，$p_2$ 從 2 漲到 4（作業第 2 題）。

完全替代：換角的時候，所得效果是 0

$U = 2x_1 + x_2$、$p_2 = 1$、$m = 30$，$p_1$ 從 3 降到 1（作業第 3 題）。

準線性：所得效果是 0

準線性（quasi-linear）的例子：$U = 4\sqrt{x_1} + x_2$、$p_2 = 1$、$m = 20$，$p_1$ 從 1 降到 0.5。相切條件 $\dfrac{2}{\sqrt{x_1}} = \dfrac{p_1}{p_2}$ 解出 $x_1 = \dfrac{4p_2^2}{p_1^2}$，裡面沒有 $m$。

效用函數替代效果所得效果一句話
完全互補 $\min\{\cdot,\cdot\}$0全部折點不會因為預算線轉動而移動
完全替代 $ax_1 + bx_2$（換角時）全部0原本沒買那個商品，$m' = m$
準線性 $f(x_1) + x_2$全部0$x_1$ 的需求跟所得無關
Cobb-Douglas有有兩個效果同方向（正常財）

阿明只吃「一個漢堡配兩包薯條」的套餐，多的漢堡或多的薯條對他都沒用。漢堡漲價後他買的漢堡變少了。減少的部分是？

這是完全互補。不管相對價格怎麼變，他都維持固定搭配，替代效果是 0。漢堡變少只是因為漲價後買得起的套餐數變少了，全部是所得效果。

補充：Hicks 的替代效果

簡報最後一頁問了一句：「在新價格下，要多少所得才能回到原來的效用水準？」這是 Hicks 的拆法。和 Slutsky 只差在「補償到哪裡」：

Slutsky 補償

補償到買得起原來的組合。補償預算線通過 A。作業指定用這一種。

Hicks 補償

補償到回到原來的無異曲線。補償預算線和通過 A 的那條無異曲線相切。

用作業第 1 題的數字比較兩種拆法

原本的效用 $U_0 = 15^2 \times 15 = 3375$。新價格 $(1, 1)$ 下，所得 $m$ 的人會選 $x_1 = \tfrac{2m}{3}$、$x_2 = \tfrac{m}{3}$，效用是 $\tfrac{4m^3}{27}$。令它等於 3375：

$$\frac{4m^3}{27} = 3375 \;\Rightarrow\; m \approx 28.35 \;\Rightarrow\; x_1 \approx 18.90$$
拆法補償所得中間點的 $x_1$替代效果所得效果
Slutsky3020+5+10
Hicks28.3518.90+3.90+11.10

總效果都是 +15，只是切的位置不同。題目寫 Slutsky 就用 Slutsky。

消費者的效用函數是 $U = x_1^2x_2$，預算限制式是 $p_1x_1 + p_2x_2 = m$。

(A) 導出 $x_1$ 和 $x_2$ 的需求函數。
(B) 令 $p_1 = 2$、$p_2 = 1$、$m = 45$，求最適消費組合。
(C) $p_1$ 從 2 降到 1，$p_2$ 和 $m$ 不變，求新的最適消費組合。

提示

(A) 用兩個條件：相切 $\text{MRS} = -\dfrac{p_1}{p_2}$，加上預算式。$MU_1 = 2x_1x_2$，$MU_2 = x_1^2$。(D) 先算「用新價格買舊組合要多少錢」。

(A) 相切條件

$$\text{MRS} = -\frac{MU_1}{MU_2} = -\frac{2x_1x_2}{x_1^2} = -\frac{2x_2}{x_1} = -\frac{p_1}{p_2} \quad\Rightarrow\quad p_1x_1 = 2\,p_2x_2$$

意思是花在 $x_1$ 的錢是花在 $x_2$ 的兩倍。

(A) 代回預算式

$$p_1x_1 + p_2x_2 = m \;\Rightarrow\; 2p_2x_2 + p_2x_2 = m \;\Rightarrow\; x_2^* = \frac{m}{3p_2},\qquad x_1^* = \frac{2m}{3p_1}$$

所得的 $\tfrac23$ 花在 $x_1$、$\tfrac13$ 花在 $x_2$，跟指數 2 和 1 的比例一樣。

(B) 代入 $p_1 = 2$、$p_2 = 1$、$m = 45$

$$x_1^* = \frac{2\times 45}{3\times 2} = 15,\qquad x_2^* = \frac{45}{3\times 1} = 15$$

原本的組合 $A = (15, 15)$。檢查：$2\times 15 + 1\times 15 = 45$ ✓

(C) $p_1$ 改成 1

$$x_1^* = \frac{2\times 45}{3\times 1} = 30,\qquad x_2^* = 15$$

新的組合 $C = (30, 15)$。$x_1$ 總共增加 $30 - 15 = 15$。

(D) 補償所得

用新價格 $(1, 1)$ 買原本的 $A = (15, 15)$：

$$m' = 1\times 15 + 1\times 15 = 30 \qquad\big(\text{或 } m' = 45 + (1 - 2)\times 15 = 30\big)$$

(D) 中間點 B

需求函數代入新價格和 $m' = 30$：

$$x_1^{B} = \frac{2\times 30}{3\times 1} = 20 \qquad\Big(x_2^{B} = \frac{30}{3} = 10\Big)$$

(D) 相減

$$\text{替代效果} = 20 - 15 = +5,\qquad \text{所得效果} = 30 - 20 = +10$$

檢查：$5 + 10 = 15$，等於總變化 ✓。兩個效果同方向，$x_1$ 是正常財。

(A) $x_1 = \dfrac{2m}{3p_1}$、$x_2 = \dfrac{m}{3p_2}$　(B) $(15, 15)$　(C) $(30, 15)$　(D) $m' = 30$，替代效果 $+5$，所得效果 $+10$。

(A) 導出 $x_1$ 和 $x_2$ 的需求函數。

提示

完全互補不能用微分。最適點一定在 L 型的折點，也就是括號裡兩個東西相等：$x_1 = 2x_2$。注意這一題變的是 $p_2$、問的是 $x_2$，所以 $m' = m + \Delta p_2 \times x_2^{A}$。

(A) 折點條件

多出來的 $x_1$ 或 $x_2$ 都不會增加效用，所以不浪費的買法是讓兩個相等：

$$x_1 = 2x_2$$

(A) 代回預算式

$$p_1(2x_2) + p_2x_2 = m \;\Rightarrow\; x_2^* = \frac{m}{2p_1 + p_2},\qquad x_1^* = \frac{2m}{2p_1 + p_2}$$

可以想成一套「2 個 $x_1$ 配 1 個 $x_2$」要價 $2p_1 + p_2$，所得能買幾套就買幾套。

(B) 代入 $p_1 = 1$、$p_2 = 2$、$m = 48$

$$x_2^* = \frac{48}{2 + 2} = 12,\qquad x_1^* = 24$$

$A = (24, 12)$。檢查：$1\times 24 + 2\times 12 = 48$ ✓

(C) $p_2$ 改成 4

$$x_2^* = \frac{48}{2 + 4} = 8,\qquad x_1^* = 16$$

$C = (16, 8)$。檢查：$16 + 4\times 8 = 48$ ✓。$x_2$ 總共變化 $8 - 12 = -4$。

(D) 補償所得

用新價格 $(1, 4)$ 買原本的 $A = (24, 12)$：

$$m' = 1\times 24 + 4\times 12 = 72 \qquad\big(\text{或 } m' = 48 + (4 - 2)\times 12 = 72\big)$$

這次是漲價，所以要多給他錢才買得起原來那一籃。

(D) 中間點 B

$$x_2^{B} = \frac{72}{2\times 1 + 4} = 12 \qquad\big(x_1^{B} = 24\big)$$

B 和 A 是同一點。

(D) 相減

$$\text{替代效果} = 12 - 12 = 0,\qquad \text{所得效果} = 8 - 12 = -4$$

完全互補沒有替代效果，$x_2$ 少掉的 4 單位全部是所得效果。
