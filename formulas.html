Ch7　顯示性偏好與指數

直接 $x \succ_D y$：選了 $x$ 的那一期，$y$ 也買得起（$p\cdot y \le p\cdot x$，且 $y \ne x$）卻沒選。
間接 $x \succ_I z$：$x \succ_D y$ 且 $y \succ_D z$，用遞移性串起來。

WARP（弱公理）：有 $x \succ_D y$，就不能有 $y \succ_D x$。
SARP（強公理）：$x$ 直接或間接顯示偏好於 $y$（$x \ne y$），$y$ 就不能直接或間接顯示偏好於 $x$。

WARP 只是必要條件；SARP 才是充要條件（滿足 SARP ⟺ 存在行為良好的偏好可以解釋資料）。違反 WARP 一定違反 SARP，反過來不一定。

  1. 列放各期的價格，欄放各期選的組合，每一格算「用這一列的價格買這一欄的組合要多少錢」。
  2. 對角線是那一期的實際花費，用紅筆標起來。
  3. 同一列裡，不超過對角線的其他格子圈起來：買得起卻沒選 → 這一列選的組合 $\succ_D$ 那一欄的組合。
  4. 查 WARP：有沒有一對組合互相被圈（$X \succ_D Y$ 且 $Y \succ_D X$）。
  5. 查 SARP：把直接關係用遞移性接起來，再看有沒有繞成一圈。
$$L_q = \frac{p^b\cdot x^t}{p^b\cdot x^b} \qquad P_q = \frac{p^t\cdot x^t}{p^t\cdot x^b} \qquad\qquad L_p = \frac{p^t\cdot x^b}{p^b\cdot x^b} \qquad P_p = \frac{p^t\cdot x^t}{p^b\cdot x^t} \qquad\qquad M = \frac{p^t\cdot x^t}{p^b\cdot x^b}$$

記法：Laspeyres 用基期當權數（固定不動的那個是 b），Paasche 用當期當權數（固定不動的那個是 t）。數量指數固定價格、比數量；價格指數固定數量、比價格。

看到等於在說結論
$P_q \gt 1$　或　$L_p \lt M$$p^t\cdot x^t \gt p^t\cdot x^b$：現在買得起基期組合卻沒選現在比較好
$L_q \lt 1$　或　$P_p \gt M$$p^b\cdot x^b \gt p^b\cdot x^t$：基期買得起當期組合卻沒選基期比較好
其他情況（例如 $L_p \gt M$、$P_p \lt M$）那個組合當時買不起，沒有透露資訊單看那個指數沒有結論

把所得補到「用新價格剛好買得起基期組合」。新預算線通過基期組合，但斜率變了；只要相對價格有變，消費者就能換到更喜歡的組合 → 一定至少一樣好，通常變好（新組合顯示偏好於基期組合）。所以用 Laspeyres 價格指數調整所得會補過頭。

完整講解與檢查器在 Ch7 顯示性偏好與指數。

Ch8　Slutsky 方程式

  1. 原本的組合 A：用舊價格、原所得 $m$ 算需求。
  2. 補償所得：$m' = m + \Delta p_1 \times x_1^A$，也就是「用新價格買舊組合 A 的花費」。
  3. 中間點 B：用新價格、補償所得 $m'$ 算需求。
  4. 最終點 C：用新價格、原所得 $m$ 算需求。
  5. 替代效果 = B − A，所得效果 = C − B，總效果 = C − A = 替代效果 + 所得效果。
商品類型（自己的價格下降時）替代效果所得效果總效果
正常財（normal good）增加增加（同方向）增加，需求線一定負斜率
劣等財（inferior good）增加減少，但比較小增加
Giffen 財增加減少，而且比較大減少，需求線正斜率

價格上漲時整張表反號。不變的規則：替代效果永遠跟價格反方向（或等於 0），所得效果的方向才要看是正常財還是劣等財。

完全互補：替代效果 = 0，總效果全部是所得效果（HW7 第 2 題）。
完全替代：角落換邊的時候，總效果全部是替代效果，所得效果 = 0（HW7 第 3 題）。
準線性：$x_1$ 的需求跟所得無關，所得效果 = 0。

Hicks 替代效果：補償到「回到原本的效用水準」，而不是「買得起原本的組合」。

完整講解在 Ch8 Slutsky 方程式。

Ch9　買與賣

$$p_1x_1 + p_2x_2 = p_1\omega_1 + p_2\omega_2 \qquad\Longleftrightarrow\qquad p_1(x_1 - \omega_1) + p_2(x_2 - \omega_2) = 0$$

稟賦點 $(\omega_1, \omega_2)$ 永遠在預算線上；價格變動時，預算線繞著稟賦點旋轉。

淨需求 $x_i - \omega_i \gt 0$：買方（net demander）；$\lt 0$：賣方（net supplier）。兩個淨需求的總值一定是 0：買東西的錢來自賣東西。

價格下跌：那個商品的買方一定變好；賣方如果繼續當賣方，一定變差。

$$p_cC + wR = m + w\bar R \qquad \text{斜率 } -\frac{w}{p_c}\text{（實質工資）} \qquad L = \bar R - R$$

$C$ 消費、$R$ 休閒、$\bar R$ 總時數、$w$ 工資、$m$ 非勞動所得。休閒的「價格」就是工資 $w$。

$U = CR$、$\bar R = 24$ 時：$R^* = 12 + \dfrac{m}{2w}$，$L^* = 12 - \dfrac{m}{2w}$，$C^* = \dfrac{m + 24w}{2p_c}$。$m$ 增加 → 休閒增加 → 勞動供給減少。

有稟賦時，價格一變，稟賦的價值也跟著變，所以多一項：

總效果 = 替代效果 + 一般所得效果 + 稟賦所得效果

完整講解在 Ch9 買與賣。

Ch10　跨期選擇

$$FV = m(1+r) \qquad\qquad PV = \frac{m}{1+r} \qquad\qquad \text{第 } t \text{ 期的 } m_t\text{：}\ PV = \frac{m_t}{(1+r)^t}$$
$$\text{終值式：}\ (1+r)c_1 + c_2 = (1+r)m_1 + m_2 \qquad\qquad \text{現值式：}\ c_1 + \frac{c_2}{1+r} = m_1 + \frac{m_2}{1+r}$$

橫軸截距 = 稟賦的現值 $m_1 + \dfrac{m_2}{1+r}$　縱軸截距 = 稟賦的終值 $(1+r)m_1 + m_2$　斜率 $-(1+r)$　一定通過 $(m_1, m_2)$

$c_1 \lt m_1$：存錢（saver），$c_2 = m_2 + (1+r)(m_1 - c_1)$；$c_1 \gt m_1$：借錢（borrower）。

$$(1+r)p_1c_1 + p_2c_2 = (1+r)m_1 + m_2 \qquad \text{斜率 } -(1+r)\frac{p_1}{p_2}$$ $$p_2 = (1+\pi)p_1 \quad\Rightarrow\quad \text{斜率 } -\frac{1+r}{1+\pi} = -(1+\rho) \qquad \rho = \frac{r - \pi}{1+\pi} \approx r - \pi$$

$r$ 名目利率、$\pi$ 通貨膨脹率、$\rho$ 實質利率（real interest rate）。近似式只有 $\pi$ 很小才準。

$r$ 下降或 $\pi$ 上升 → 實質利率下降 → 預算線變平。存錢的人（繼續存錢的話）變差；借錢的人變好。

$$\text{三年期證券：}\ PV = \frac{m_1}{1+r} + \frac{m_2}{(1+r)^2} + \frac{m_3}{(1+r)^3}$$ $$\text{債券（bond）：}\ PV = \frac{x}{1+r} + \frac{x}{(1+r)^2} + \cdots + \frac{x}{(1+r)^{T-1}} + \frac{F}{(1+r)^T} \qquad\qquad \text{永續債（consol）：}\ PV = \frac{x}{r}$$

現值就是「現在最多願意付多少」。利率上升，現值下降（每一項的分母都變大）。價格高於現值就是太貴。

完整講解在 Ch10 跨期選擇。

容易寫錯的正確做法
WARP 沒違反，就直接寫 SARP 也沒違反SARP 還要把間接關係算進來再查一次。HW6-1 就是 WARP 過、SARP 不過。
花費表的列和欄弄反列 = 價格、欄 = 組合。比較大小時是同一列（同一期的價格）跟對角線比。
Laspeyres 和 Paasche 的權數弄反L 用基期（b）當權數，P 用當期（t）當權數。價格指數的權數是數量，數量指數的權數是價格。
指數沒有結論時硬下結論$L_p \gt M$ 或 $P_p \lt M$ 只代表「那個組合當時買不起」，要寫「單看這個指數無法判斷」，並說明原因。
Slutsky 的 $m'$ 用舊價格去算$m'$ = 新價格 × 舊組合。算完檢查：舊組合在新價格下剛好花掉 $m'$。
替代效果和所得效果的順序、正負號寫反替代 = B − A（先轉），所得 = C − B（後移）。加起來要等於 C − A；數量減少就寫負號。
$\min\{x_1, 2x_2\}$ 的折點寫成 $x_2 = 2x_1$讓括號裡兩個東西相等：$x_1 = 2x_2$。代 $(4, 2)$ 檢查。
稟賦題把所得當成固定不變所得 = $p_1\omega_1 + p_2\omega_2$，價格一變所得就變，預算線繞稟賦點轉，要重算。
淨需求的正負號寫反淨需求 = 消費 − 稟賦。正的是買方，負的是賣方。最後用「總值 = 0」檢查。
現值只除以 $(1+r)$ 一次第 $t$ 期的錢要除以 $(1+r)^t$：第 2 年除以 $1.1^2 = 1.21$，第 3 年除以 $1.1^3 = 1.331$。
把 $r - \pi$ 當成精確的實質利率精確值是 $\rho = \dfrac{r - \pi}{1 + \pi}$；$r - \pi$ 只是近似。題目問 exact 就要用除的。
只寫數字，沒有寫結論題目問 better off / worse off、buyer / seller、steeper / flatter 時，最後一定要用一句話回答。

考卷是英文的。遇到 derive 要留符號、寫過程；遇到 find 或 calculate 代數字；遇到 explain、compare 一定要用一句完整的話下結論。算完多花十秒做檢查：花費加起來等於所得、淨需求總值等於 0、替代效果加所得效果等於總變動。
